设计系统还原度

设计令牌

颜色、字号、圆角、动效曲线与高程全部按 WinUI 的 ControlFillColor / CardStrokeColor 体系取值，浅暗两套主题自动切换。

状态完整

Rest / Hover / Pressed / Disabled / Selected 五种视觉状态，键盘焦点使用 Fluent 双层描边，支持键盘与指针两种焦点模式。

XAML 直通

内置轻量 XAML 解析器，粘贴 WinUI 3 的 XAML 片段即可渲染成真实控件，方便对照迁移。

无框架

Custom Elements + CSS 变量，可直接嵌入任何页面，也可与 React / Vue / 原生项目共存。

快速开始

引入四个样式文件与脚本，然后像写 HTML 一样使用控件。

<link rel="stylesheet" href="src/css/tokens.css">
<link rel="stylesheet" href="src/css/winui.css">
<link rel="stylesheet" href="src/css/controls.css">
<link rel="stylesheet" href="src/css/surfaces.css">

<wui-button variant="accent" icon="add">新建</wui-button>
<wui-textbox header="用户名" placeholder="请输入" clearable></wui-textbox>
<wui-switch checked>启用通知</wui-switch>

<script src="src/js/core.js"></script>
<script src="src/js/popup.js"></script>
<script src="src/js/inputs.js"></script>
<script src="src/js/collections.js"></script>
<script src="src/js/overlays.js"></script>

映射关系

XAML 标签 → 自定义元素
Button            → wui-button
TextBox           → wui-textbox
ToggleSwitch      → wui-switch
NavigationView    → wui-nav-view
ListView          → wui-list-view
ContentDialog     → WinUI.dialog()
StackPanel        → .wui-stack
Border            → .wui-card
属性映射
Content="确定"        → 文本内容
PlaceholderText="…"  → placeholder
IsChecked="True"     → checked
IsExpanded="True"    → expanded
Severity="Success"   → severity
Margin="12,8"        → margin: 8px 12px
Spacing="12"         → gap: 12px
Width="220"          → width: 220px
